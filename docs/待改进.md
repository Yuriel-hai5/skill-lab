# 待改进清单

**用法**：用 skill 的时候哪里卡住、哪里看不懂、哪里给的方案不对 —— 随手记到这里。
攒够了就按 `路线图.md` 的优先级动手改。

> **不用等"想清楚了"再记。** 一句话就够。改的时候再展开。

---

## 记录格式

| 日期 | 当时在做什么 | 卡在哪 / 哪里不对 | 归到哪个方向 | 状态 |
|---|---|---|---|---|
| 2026-09-16 | （示例）想写毕设论文 | 说"我要写论文"完全没反应，对不上配方 | 方向 1 | 待办 |

**方向编号**：1 = 扩配方 / 2 = 工坊化 / 3 = 配方质量 / 4 = 分享体验

## 记的时候可以问自己

- **说了一句话，它有没有反应？** 没反应 → 缺配方（方向 1）或 description 写得不对
- **它给了方案，但你看不懂第一步干啥？** → 配方太抽象（方向 3）
- **它给的顺序不对 / 跳步了？** → 配方逻辑要改（方向 3）
- **它推荐了一个你没装的 skill？** → 降级路径不清楚（方向 3）
- **想做个新 skill，不知道放哪？** → 该工坊化了（方向 2）
- **别人装不上 / 装错了？** → 分享体验（方向 4）
