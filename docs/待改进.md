# 待改进清单

**用法**：用 skill 的时候哪里卡住、哪里看不懂、哪里给的方案不对 —— 随手记到这里。
攒够了就按 `路线图.md` 的优先级动手改。

> **不用等"想清楚了"再记。** 一句话就够。改的时候再展开。

---

## 什么时候该记：看感觉，不用判断

**你不需要判断"方案技术对不对"**（那要技术积累），只需要判断「**它有没有帮到我**」。
下面全是体感信号，一条都不需要懂技术：

| 你的感觉 | 大概率是 |
|---|---|
| 看完不知道**第一步干啥** | 配方太抽象（方向 3） |
| 照着做**做不通** / 它**跳步**了 | 配方逻辑要改（方向 3） |
| 它问的问题**我答不上来**，或答了之后**它跑偏** | 问得不对 / 判错阶段 |
| 绕了几轮**还没落到具体动作** | 在空转 |
| 它推荐了个**我没装的 skill，没说怎么办** | 降级路径不清楚（方向 3） |
| 说了一句话，**它完全没反应** | 缺配方（方向 1）或 description 不对 |
| 想做个新 skill，**不知道放哪** | 该工坊化了（方向 2） |
| **别人装不上 / 装错了** | 分享体验（方向 4） |
| 单纯觉得「**这不是我想要的**」 | 判错了 —— 记下来，不用归因 |

> **不用判断"是不是卡住"。** 觉得别扭 / 不对 / 没帮上，就记一句。
> 一句话就够，不用想清楚 —— **归因是改的时候才做的事**，现在只要把感觉留下来。

## 记录格式

| 日期 | 当时在做什么 | 卡在哪 / 哪里不对 | 归到哪个方向 | 状态 |
|---|---|---|---|---|
| 2026-09-16 | （示例）想写毕设论文 | 说"我要写论文"完全没反应，对不上配方 | 方向 1 | 待办 |

**方向编号**：1 = 扩配方 / 2 = 工坊化 / 3 = 配方质量 / 4 = 分享体验
